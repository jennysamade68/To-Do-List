# 📝 To-Do List

**Stay Organized. Stay Focused. Get Things Done.**

To-Do List is a simple and easy-to-use task management app designed to help you organize your day, keep track of important tasks, and never miss a reminder.

Create tasks, set dates and reminders, mark tasks as completed, and use AI-powered predictions to help you stay organized.

---

## 📱 Download the Android App

### 👉 [Download To-Do List v1.0.0 APK](https://github.com/jennysamade68/To-Do-List/releases/latest)

1. Open the link above on your Android phone.
2. Under **Assets**, select **app-release.apk**.
3. Wait for the APK to download.
4. Open the downloaded APK.
5. If Android asks for permission to install apps from this source, allow it.
6. Tap **Install**.
7. Open **To-Do List**.

> **Note:** You may need to allow installation from your browser or file manager in Android settings.

## 🔔 Task Reminders

Never forget an important task.

To set a reminder:

1. Create a task.
2. Press the **🔔 reminder icon**.
3. Select a date and time.
4. Save the reminder.
5. Allow notification permission when Android asks.

The app will send a notification at the scheduled time.

> **Important:** Android notification permission must be enabled for reminders to work.
